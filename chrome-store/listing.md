# Chrome Web Store: what to paste where

Upload `kivli-0.2.2.zip` from this folder. Everything below is in the order of the dashboard's left-hand menu.

## Store listing

**Description**

Save the page you're on to your Kivli library, without leaving it.

Kivli is a design library that does the filing. Press the button on any page and choose what to keep:

• Website: captured full length on desktop and mobile, then tagged and summarised.
• Component: grab what's on your screen and crop the part you want.
• Resource: a tool, typeface or article, described and put in a folder.
• Visual: tick the images you want from the ones on the page, with the maker credited.

Add it to a collection and leave a note as you save. The panel also tells you when a page is already in your library.

You need a Kivli account, and Kivli is invite-only. The extension looks at a page only when you press its button.

## Privacy

**Single purpose**

Saves the page the user is viewing, or images and a screen grab from it, to the user's own Kivli design library.

**activeTab justification**

When the user presses the button, the extension needs the address, title and icon of that one tab to save it, and access to it if the user asks for its images or a picture of what's visible. It has no access to any other tab.

**scripting justification**

When the user chooses Visual, one function packaged in the extension runs once in the current tab to list the images and clips on the page, so the user can tick the ones to save. It doesn't change the page and isn't run on any other page.

**storage justification**

Remembers which kind of save the user last chose, and the reason a save failed if the panel was closed before it finished.

**Host permission justification**

https://specimen-gamma-six.vercel.app is Kivli itself. The permission lets the extension send a save to the user's own account using the Kivli sign-in already in their browser. No other site is requested.

**Remote code:** No, I am not using remote code

**Data usage, tick these two:**
- Web history (the address and title of a page, when the user opens the panel on it or saves it)
- Website content (the images the user ticks, and the screen grab they ask for)

Leave the others unticked. Then tick all the certifications under them, once you've read them.
